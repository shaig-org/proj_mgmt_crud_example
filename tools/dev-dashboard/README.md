# Dev Dashboard

Standalone local viewer that consolidates three developer-facing artifact
surfaces under a single Vite + React + TypeScript app:

- **Scenarios** — walkthroughs generated by `frontend/` scenario tests.
- **Capabilities** — route-vs-capability report from the backend analyzer.
- **Traces** — per-scenario trace artifacts from pytest-tracer.

The dashboard binds to `127.0.0.1` and is view-only. It never calls the
product FastAPI backend.

## Commands

All commands are run with `npm --prefix tools/dev-dashboard` (no `cd`).

| Command | Purpose |
|---|---|
| `npm --prefix tools/dev-dashboard install` | Install dependencies. |
| `npm --prefix tools/dev-dashboard run dashboard` | Boot the dashboard on 127.0.0.1:5179. Runs `check-staleness` first. |
| `npm --prefix tools/dev-dashboard run dashboard:refresh` | **One command, all tabs** — regenerate every artifact the dashboard reads (capabilities report + baseline, capabilities git-diff, e2e-traces, walkthrough GIFs/screenshots/manifest, pytest-tracer `.trace-artifacts`, staleness). Non-fatal per-step. Wraps `devtools/refresh-dashboard-artifacts.sh` — see that script's header for the full artifact → tab map and flags. |
| `npm --prefix tools/dev-dashboard run dashboard:check` | Re-run only the staleness check. |
| `npm --prefix tools/dev-dashboard run lint` | Lint. |
| `npm --prefix tools/dev-dashboard run typecheck` | TS strict check. |
| `npm --prefix tools/dev-dashboard run test` | Vitest unit tests. |
| `npm --prefix tools/dev-dashboard run smoke` | Playwright smoke suite (boots its own Vite server). |

## Adding a new aspect

A new aspect is one directory under `src/aspects/<id>/` exporting an
`Aspect<TData>`, plus one entry in `src/aspects/index.ts` and one entry in
`scripts/aspects.config.mjs`. See `src/aspects/types.ts` for the contract.

## Security

The Vite dev server exposes selected repo directories under `/artifacts/`.
It binds to localhost only. Do not expose the port beyond the loopback
interface.
